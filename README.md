## 📌 What is BAUST Khulna CSE Hub?

**BAUST Khulna CSE Hub** is a centralized, student-built web platform for the Computer Science & Engineering department at Bangladesh Army University of Science and Technology (BAUST), Khulna Campus.

The goal is simple — students shouldn't have to hunt through scattered WhatsApp groups, Facebook posts, and unofficial channels to find the information they need. This hub brings department notices, academic resources, course materials, schedules, and student tools into a single, clean, always-accessible platform.

Built by a student. For students. Free forever.

## ✨ Key Features

| Feature | Description |
|---|---|
| 📋 **Department Notices** | Academic announcements, exam schedules, and official department updates in one place |
| 📚 **Course Resources** | Lecture notes, slides, past question papers, and study materials organized by semester and course |
| 🗓️ **Class Schedule** | Up-to-date timetables for all semesters — accessible anytime, anywhere |
| 🏆 **Result Archive** | Semester results and academic performance records for easy reference |
| 🔗 **Important Links** | Quick access to university portals, library, department contacts, and official websites |
| 👨‍💻 **Student Projects** | Showcase of CSE student projects, research, and academic achievements |
| 📱 **Responsive Design** | Fully optimized for mobile, tablet, and desktop — works on any device, any screen |
| ⚡ **Fast & Lightweight** | Built with pure HTML/CSS/JS — loads instantly with zero framework overhead |

## 🚀 Getting Started

### Run Locally
```bash
# 1. Clone the repository
git clone https://github.com/nasif120696-collab/baust-khulna-cse-hub.git

# 2. Navigate into the project
cd baust-khulna-cse-hub

# 3. Open in browser — no setup needed
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux
```

### Deploy Your Own Instance (Free)

**GitHub Pages:**
```
1. Fork this repository
2. Settings → Pages → Source: main branch → / (root)
3. Save → live at: https://YOUR-USERNAME.github.io/baust-khulna-cse-hub
```

**Vercel:**
```
1. vercel.com → New Project → Import from GitHub
2. Select this repo → Deploy
3. Live in ~30 seconds with a free Vercel URL
```

## 🤝 Contributing

This is a community platform — every contribution from BAUST CSE students and alumni is welcome.
```bash
# 1. Fork the repository

# 2. Clone your fork
git clone https://github.com/YOUR-USERNAME/baust-khulna-cse-hub.git
cd baust-khulna-cse-hub

# 3. Create a feature branch
git checkout -b feat/add-semester-5-notes

# 4. Make changes and commit
git commit -m "feat: add Semester 5 Data Structures notes"

# 5. Push and open a Pull Request
git push origin feat/add-semester-5-notes
```

### Ways to contribute:
- 📄 Upload course notes, slides, or past question papers
- 🐛 Report outdated information or broken links
- 🗓️ Update class schedules or exam timetables
- 🎨 Improve UI design or mobile responsiveness
- 💡 Suggest new features via GitHub Issues
